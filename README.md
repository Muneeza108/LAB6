# Lab Task 06 – Abstract Data Types (ADT)

## Objective

To implement simple ADTs in Java, use interfaces to define contracts, and apply abstraction and encapsulation principles.

## Tasks Completed

* Implemented Stack ADT using LIFO.
* Applied data encapsulation using private fields and getters.
* Used `List` with `ArrayList` and `LinkedList`.
* Designed a Library System ADT using an interface.
* Implemented a Student Collection ADT.
* Created JUnit tests for Student Collection operations.

## How to Run

Open the project in Apache NetBeans and run the required Java classes.
Run `StudentCollectionImplementationTest` to execute the JUnit tests.
